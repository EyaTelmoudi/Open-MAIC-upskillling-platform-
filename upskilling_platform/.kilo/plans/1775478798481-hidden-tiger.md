## API Contract

```
POST /api/v1/learning/bookmarks
Body: { "course_id": "uuid", "lesson_id": "uuid" } (one required)
Response: { "id": "uuid", "course_id": "uuid", "lesson_id": "uuid", "created_at": "datetime" }

GET /api/v1/learning/bookmarks
Response: [{ "id": "uuid", "course_id": "uuid", "lesson_id": "uuid", "created_at": "datetime" }]

DELETE /api/v1/learning/bookmarks/{id}
Response: 204 No Content
```
